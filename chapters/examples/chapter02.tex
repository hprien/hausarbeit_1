This term paper is partially based on research papers that are still in pre-print or have not received much attention yet because they have been published recently. As the technology of \ac{AI} and especially \ac{LLM}s is still evolving and heavily underlies broad attention, some aspects might change and evolve in future.\\

\noindent There are three main differences regarding the knowledge based on which the penetration test is performed. Black-, Gray- and White-Box penetration testing. \cite{Rane_2024}

Traditional penetration testing tooling already implemented various automation to support penetration testers \cite{Osman_2025}.

Earlier approaches to automate the process of penetration testing leveraged Reenforcement Learning \cite{Confido_2022}. However scaling these approaches to an production ready state brought up difficulties \cite{Schwartz_2019}.

Leveraging \ac{LLM}s for penetration testing shows better results and scalability. The project PentestGPT also describes an agentic approach for orchestrating \ac{LLM}s beneficially. \cite{Deng_2024}

Multiple tools already implement \ac{AI} for penetration testing to support human penetration testers \cite{Kozlovska_2025}.
